regenerated from the committed code.

## 3. Benchmark contamination (fails Ali's criterion and the leakage test)

The unknown-world criterion is *"no prior knowledge of tools, rules, or failure modes."*
`runner/hypothesis.py` violates it directly. The prompt handed to the model contains:

```
MANDATORY COMMANDS FOR EACH TASK TYPE (copy exactly, do not modify):
config-parsing:              awk -F' = ' '/ = / {gsub(/ /, "", $2); printf ...}' world_files/*.conf | head -1
log-pattern-detection:       grep -c 'specific_pattern' world_files/*.log | awk ...
file-hash-verification:      sha256sum world_files/*.bin | head -1 | awk ...
command-output-transformation: echo 'data' | tr 'a-z' 'A-Z' | awk ...
environment-variable-resolution: echo $HIDDEN_VAR | rev | awk ...
```

These are the gold-producing commands, not hints. Verified:

```
$ sha256sum world_files/file_8.bin | head -1 | awk '{print "{\"hash\": \"" $1 "\"}"}'
{"hash": "53595000c4501fffb37a9e7b052007d19bf7b04c05c8f0f63d2ae782e83369fa"}
$ # gold_world2.json, W2-002:
{"hash": "53595000c4501fffb37a9e7b052007d19bf7b04c05c8f0f63d2ae782e83369fa"}
```

Identical. Every `world_files/*.bin` is `b"hidden_file_content"`, so `head -1` always hits gold.

This leak was exercised in practice. `results/batch1/hypothesis_log.md` records the model
issuing exactly that command and producing exactly that gold hash — the one of batch1's
three correct answers.

Additional leaks:

- `world/world_manifest.json` ships `families` (all 5 task-family names) to the agent, so the
  task taxonomy is known before any probing.
- The runner executes commands with `cwd = world/`, and `gold_world2.json` sits in that same
  directory (`world/gold_world2.json`). `ls` alone reveals the answer key. No sandbox
  separates agent-visible files from withheld gold.
- `runner/discovery.py`'s `discover_filesystem()` runs `find / -maxdepth 3`, `env`, and lists
  `$HOME` — it maps the host, not the world, and discloses host state to the model.
