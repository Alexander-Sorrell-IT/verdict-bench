Supersedes `PLAN_2026-11-26.md`. Written 2026-11-27.

## Why this replaces the old plan

Three things were wrong in the last revision's estimate, and all three came from the same
cause: **treating a repo description as a fact.**

| Claim | Status after reading the code |
|---|---|
| `touchstone` is "the reproducibility machinery" | **RETRACTED.** It is NVIDIA HGX sort-line telemetry (fct/bbx/perf_signature/thermal). Unrelated. Found by pattern-matching the phrase "replay harness". |
| `CLI-Enforcement` "is the arm" | **PARTIAL.** 16k lines of real hook-level enforcement — stage→model-event mapping, anti-hallucination, sandbox, cascade, points/tiers scorecard. A source for the gates, not a benchmark arm. Port concepts. |
| `alignerr-task-factory` "is the world generator" | **PARTIAL, STRONG.** Seed → scaffolded task with **18 local gates**, and it *refuses to ship paradoxes* (unverifiable tasks). The discipline is transferable; the generator is not. |

Total estimated effort went 32 → 22-26 → 10-15 → **back to 16-20 h** once the reading was done.

## Ground rules (each earned tonight)

1. **Read before claiming.** A description is a claim until code has been opened. Every entry below is tagged `READ` or `TREE-ONLY`; only `READ` items are banked in the estimate.
2. **No number without reproduction.** A result that cannot be regenerated from committed code by someone else does not exist.
3. **Keys used properly.** `gh api users/<name>/repos` is anonymous and hides all private repos. The correct form is `gh auth switch --user <acct>` then `gh api user/repos`. This error cost a ~100-repo undercount.
4. **No number derived from another number's prose.** `RESULTS.md` claimed a model, endpoint and wall clock that its own launcher contradicts.
